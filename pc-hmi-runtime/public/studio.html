Any unsaved Alarm Setup changes will be lost if the Project Window Size setting is changed from a PanelView Plus to PanelView Plus Compact terminal, or vice versa.

If the window size no longer matches the graphic layout, Studio asks whether to scale all displays and global objects so they fill the new size.
